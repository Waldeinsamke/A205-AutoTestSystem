## 〇、开工前的安全提示

| ⚠️ | 事项 |
|---|---|
| 1 | **PE42482 控制脚（V1~V4/LS）绝对最大额定 3.6 V，严禁 5 V 驱动。** 接线错误会永久损坏芯片。 |
| 2 | 任何带电插拔动作前，先断开 USB 供电。 |

## 一、总体接线图

```
                    ┌─────────────────────────────────────────┐
   RF 信号源 ──────►│ CON9 (RFC)   圆盘 #1 (RF 路)            │
                    │              RF1..RF8 ──► CH1..CH8 的 RF 口│
                    └─────────────────────────────────────────┘

                    ┌─────────────────────────────────────────┐
   LO 信号源 ──────►│ CON9 (RFC)   圆盘 #2 (LO 路)            │
                    │              RF1..RF8 ──► CH1..CH8 的 LO 口│
                    └─────────────────────────────────────────┘

                    ┌─────────────────────────────────────────┐
接收机 IF 输出口 ──►│ CON9 (RFC)   圆盘 #3 (输出路)           │
                    │              RF1..RF8 ──► 频谱仪输入       │
                    └─────────────────────────────────────────┘

                    ┌─────────────────────────────────────────┐
                    │        驱动板 LB-A205-MTX-01            │
                    │  USB ─► MCU ─► V1 V2 V3 V4 ─┬─► 圆盘 #1 │
                    │           (CH340, 115200)    ├─► 圆盘 #2 │
                    │                             └─► 圆盘 #3 │
                    └─────────────────────────────────────────┘
```

### ⚠️ 方向不可接反

圆盘模块的 **CON9 = 公共端 RFC（输入侧）**，**CON1~CON8 = 八路分路（输出侧）**。

接反的后果：信号从 8 个分路同时散出，等效于完全没有切换功能，且不会有任何报错。

**判断方法**：用信号源从 CON9 灌入，逐个测 CON1~CON8，只有接法正确时才能测到"只有一路有信号、其余为噪声底"。

## 二、驱动板与圆盘模块的接线

### 2.1 每块模块 6 根线

| 驱动板端子 | 信号 | 接到圆盘模块 J4 的 | 说明 |
|---|---|---|---|
| 1 | VDD_3V3 | VDD | 3.3 V 供电 |
| 2 | GND | GND | 地 |
| 3 | V1 | V1 | 控制位 1 |
| 4 | V2 | V2 | 控制位 2 |
| 5 | V3 | V3 | 控制位 3 |
| 6 | V4 | V4 | 隔离位 |

**LS 不在接线清单内** —— 在驱动板上把该模块的 LS 脚与 GND 并接短接（正码）。

> ⚠️ 驱动板端子位序必须与圆盘模块 J4 的实际脚位对齐。**J4 脚位未知前不要盲目接线**，先按 §三 完成实测。

### 2.2 控制线分组：A 组（RF+LO）与 B 组（输出路）

驱动板提供**两组**控制线，各 4 根：

```
A 组（V1 / V2 / V3 / V4）──┬──► 圆盘 #1（RF 路）
                          └──► 圆盘 #2（LO 路）

B 组（V1' / V2' / V3' / V4'）──► 圆盘 #3（输出路）
```

**为什么 RF 路与 LO 路可以共用**：两者始终成对作用于同一个接收通道，没有需要错开的场景。

**为什么输出路必须独立**：「通道间隔离度」测试需要构造

```
RF 信号源 → A 组（切 CH1）→ 接收机 CH1 的 RF 口（注入强信号）
                                      ↓ 接收机内部串扰
接收机 CH2 的 IF 输出口 → B 组（切 CH2）→ 频谱仪（读漏过来的信号）
```

即 **RF 输入通道 ≠ 输出读数通道**。若三块模块共用一组控制线，此场景无法构造。

> 项目规划书 §4.3.5 第 16 项「通道间隔离度」当前为 ⬜ Stub 占位，正是等待此能力落地。

**独立性的价值**：切换 B 组完全不影响 A 组，反之亦然。

## 三、圆盘模块上电前的检查（必做）

### 3.1 J4 脚位实测

**工具**：万用表（Ω 档 + V 档）

**步骤**：

1. 模块**不接任何线**，万用表打 Ω 档
2. 一表笔接模块 GND（任意接地点，如 SMA 外壳），另一表笔逐个点 J4 的 8 个脚
3. 记录每个脚对 GND 的电阻值

**判定表**：

| 测得电阻 | 判定 |
|---|---|
| ≈ 0 Ω（< 5 Ω） | **GND** |
| 很大（> 100 kΩ） | 可能是 **VDD / LS / V1~V4** |
| 中间值 | 需换档复测，可能有下拉/上拉 |

4. 对"很大"的那几个脚，用**直流电压档**配合驱动板通电状态复测：
   - 接 3.3 V 的是 **VDD**
   - 恒为 0 V 的是 **V1~V4 / LS**（无上拉时）

**记录表**（填好贴在模块上）：

```
J4 脚位定义（模块编号：______）
┌────┬────────┬──────────────┬────────────┐
│脚位│ 信号   │ 对 GND 电阻  │ 备注       │
├────┼────────┼──────────────┼────────────┤
│ 1  │        │              │            │
│ 2  │        │              │            │
│ 3  │        │              │            │
│ 4  │        │              │            │
│ 5  │        │              │            │
│ 6  │        │              │            │
│ 7  │        │              │            │
│ 8  │        │              │            │
└────┴────────┴──────────────┴────────────┘
```

### 3.2 供电电压确认

⚠️ **这一步决定驱动板方案是否需要改动。**

| J4 上 VDD 实测 | 结论 | 驱动板应对 |
|---|---|---|
| **3.3 V** | ✅ 理想 | 驱动板 3.3 V LDO 直接供电，控制线直连 |
| **5 V** | ⚠️ 需处理 | VDD 由驱动板独立 5 V 供电；**控制线必须加电平转换**（74LVC2T45 / TXS0102），严禁 5 V 直连 |
| **其他（如 1.8 V）** | ⚠️ 需处理 | 需查模块原理图确认 |

> PE42482 的 VDD 合法范围是 2.3 ~ 5.5 V，所以 5 V 供电本身对芯片没问题；**问题只在控制脚不能超过 3.6 V**。

### 3.3 LS 接法确认

| LS 对 GND 电阻 | 判定 | 处理 |
|---|---|---|
| ≈ 0 Ω | 已是**正码**（LS=0） | 保持，驱动板 LS 短接 GND |
| ≈ 1 MΩ | 是**反码**（LS=1，内部上拉） | **需统一**：更换 R1（0 Ω 0402）位置，把 LS 改为接地 |

**三块模块必须统一**。若不一致，需在装配时统一处理（用 0 Ω 电阻或直接短接）。

## 四、驱动板自检（不接射频）

### 4.1 上电检查

| # | 检查项 | 方法 | 通过标准 |
|---|---|---|---|
| P1 | 电源 | 万用表测 3V3 端子对 GND | 3.2 ~ 3.4 V |
| P2 | 5V 输入 | 测 USB VBUS | 4.75 ~ 5.25 V |
| P3 | 串口枚举 | 设备管理器 | 出现 CH340 串口（COMx） |
| P4 | 固件启动 | 串口助手发 `AA 55 04 00 05` | 收到版本帧 `AA 55 04 xx 00 ...` |
| P5 | V4 默认态 | 上电瞬间测 V4 脚 | **必须为高（隔离态）** |

> P5 最重要：若上电瞬间 V4 为低，芯片可能在 V1~V3 随机状态下误接通某一路。

### 4.2 控制脚静态测试

用万用表测驱动板输出端子（此时固件可先不发命令，或用固件的单步测试功能）：

| 命令 | V4 | V1 | V2 | V3 | 期望隔离状态 |
|---|---|---|---|---|---|
| 发送 `CMD 0x02`（隔离） | **1** | 0 | 0 | 0 | 全端口 50 Ω |
| 发送 `CMD 0x01 ch=1` | 0 | 见 §五 映射表 | | | RF1 导通 |

## 五、通道编码映射实测（最关键的一步）

### 5.1 为什么必须实测

数据手册 Table 5 的真值表在 PDF 文本化后**列对齐存在歧义**，不同的列解读会给出完全不同的编码（如 V1 是否为最高位、V4 是否参与通道选择等）。

**填错的严重后果**：矩阵切到"通道 3"，实际导通的是"通道 5"。接收机在收 CH3，信号却进了 CH5 → 读数为 −∞ 或极低值。**系统不会报任何错**，报表数据完全失真。

**因此必须实测填表，不允许凭推导。**

### 5.2 测试步骤

**设备**：信号源 + 频谱仪（不需要矢网）

```
信号源 ──► 圆盘 CON9 (RFC)
频谱仪 ──► 圆盘 CON1 (RF1)     ← 逐个换到 CON2..CON8
```

**步骤**：

1. 信号源设 100 MHz、−20 dBm、连续波
2. 频谱仪中心频率 100 MHz，Span 足够大
3. 依次把频谱仪接在 CON1 ~ CON8，每次记录读数
   - **期望**：只有当前选中的那个 CON 有信号，其余在噪声底
4. 通过驱动板依次发送 8 条切通道命令（ch = 1~8）
5. 每发一条，就扫一遍 8 个 CON，记录**哪个 CON 有信号**
6. 填入下表

### 5.3 ⚠️ A 组与 B 组必须分别实测

**两块模块的 LS 接法可能不同**（一块正码、一块反码），这会导致编码表不一致。

| 组 | 覆盖模块 | 实测方式 |
|---|---|---|
| **A 组** | 圆盘 #1（RF 路） | 用 `CMD 0x01` 逐个切通道 |
| **B 组** | 圆盘 #3（输出路） | 用 `CMD 0x06` 逐个切通道 |

**实测方法**：每次只接**一块**模块做测试 —— A 组阶段先不接 #3，B 组阶段先不接 #1/#2（或把未测模块的隔离位置 1）。

> 若两块模块的编码表实测结果**完全一致**（同型号 + 同 LS 接法），固件可用同一张表；否则需要两张表。
> 建议在固件中保留两张表的结构（`g_channel_code_a[8]` / `g_channel_code_b[8]`），
> 即使当前填相同值 —— 后续换板时不必改固件结构。

### 5.4 映射表（实测后填写）

```
固件查表数组，索引 = 通道号 - 1
┌────────┬──────────────┬───────────────┬─────────────┐
│ 通道号 │ 实际导通端口 │ V3 V2 V1 码值 │ 是否与预期 │
│        │              │  (0x0 ~ 0x7)  │    一致     │
├────────┼──────────────┼───────────────┼─────────────┤
│   1    │              │               │            │
│   2    │              │               │            │
│   3    │              │               │            │
│   4    │              │               │            │
│   5    │              │               │            │
│   6    │              │               │            │
│   7    │              │               │            │
│   8    │              │               │            │
└────────┴──────────────┴───────────────┴─────────────┘

A 组表 g_channel_code_a[8]：______________
B 组表 g_channel_code_b[8]：______________
两组是否一致：□ 一致  □ 不一致（需两张表）
```

**校验规则**（自动检查，固件或上位机可内置自检）：

- 8 组码值必须**互不相同**
- 8 组码值必须落在 0x0 ~ 0x7 范围内（V4 不参与通道选择）
- 驱动通道 1~8 时，实际导通端口必须依次为 RF1 ~ RF8

### 5.5 反向验证

映射表填好后，做一次闭环验证：

| 步骤 | 动作 | 期望 |
|---|---|---|
| 1 | A 组切到 CH3 | CON3 有信号 |
| 2 | B 组切到 CH5 | CON5 有信号（**A 组不受影响，仍是 CH3**） |
| 3 | 接收机发 `0D 11 03 04 00 00 0A`（Mode3） | 频谱仪读到有效中频信号 |
| 4 | 矩阵切到 CH3，接收机发 `0D 11 05 04 00 00 0A` | 频谱仪读到 −∞ 或极低值 |

**步骤 2 是分组独立性的验证** —— 证明 B 组切换不影响 A 组。
**步骤 4 是关键的负向验证** —— 证明系统能识别"矩阵与接收机通道不匹配"的情况。

## 六、射频性能基线实测

### 6.1 目的

矩阵插损会**直接计入增益报表**。必须建立基线数据，供软件补偿。

**背景数据**：项目已知 Mode3 实测增益仅 6~10 dB（规格 18.5~21.5 dB，差约 11 dB），根因待排查。引入矩阵后差距会进一步扩大 —— **基线数据是区分"矩阵引入"与"原有问题"的关键依据。**

### 6.2 测试方法

```
信号源 ──► [固定衰减器] ──► 圆盘 CON9 ──► 圆盘 CONx ──► 频谱仪
```

**固定衰减器的作用**：保护频谱仪输入（PE42482 最大输入 33 dBm，但频谱仪参考电平通常在 −30 dBm 附近）。

**步骤**：

1. 固定信号源频率 100 MHz、功率 −20 dBm
2. 频谱仪测**直连**（不经矩阵）时的读数 → `P_ref`
3. 接入矩阵，选通 CON1，测读数 → `P_1`
4. 换选通 CON2 ~ CON8，各测一次 → `P_2` ~ `P_8`
5. 换频率重复：**108 MHz / 1000 MHz / 3500 MHz / 7850 MHz** 四个点

### 6.3 记录表

```
┌──────────┬──────────┬──────────┬──────────┬──────────┬──────────┐
│ 频率      │ 直连读数 │ CON1     │ CON2     │ ...      │ 极差     │
│ (MHz)    │ P_ref    │ 插损 dB  │ 插损 dB  │          │ (dB)     │
├──────────┼──────────┼──────────┼──────────┼──────────┼──────────┤
│   108    │          │          │          │          │          │
│  1000    │          │          │          │          │          │
│  3500    │          │          │          │          │          │
│  7850    │          │          │          │          │          │
└──────────┴──────────┴──────────┴──────────┴──────────┴──────────┘

插损 = P_ref − P_x   （正值）
```

### 6.4 判定标准

| 指标 | 目标 | 依据 |
|---|---|---|
| 插损 @ 108 MHz | < 1.2 dB | 手册 10–100 MHz 档 typ 0.7 dB |
| 插损 @ 3500 MHz | < 1.6 dB | 手册 2–4 GHz 档 typ 0.9 dB |
| **插损 @ 7850 MHz** | **< 2.0 dB** | **手册 6–8 GHz 档 max 1.6 dB，只剩 150 MHz 余量，必须实测** |
| 通道间极差 | < 0.5 dB | 极差大说明通道间不一致，影响通道间增益一致性测试 |
| 隔离度 @ 3500 MHz | > 35 dB | 手册 2–4 GHz 档 typ 40 dB |

### 6.5 三块模块分别测量

三块模块（RF 路 / LO 路 / 输出路）**分别测量插损**，得到三个独立的补偿值。

因为补偿发生在不同路径上：

| 路径 | 插损影响 |
|---|---|
| RF 路 | 影响**发射功率**，进而影响增益计算（`gain = peak − RF功率`） |
| LO 路 | 影响本振电平，间接影响增益与开关 |
| 输出路 | **直接影响 peak 读数**，是三者中最敏感的 |

**输出路的插损必须精确标定**，否则所有增益读数都带固定偏差。

## 七、与接收机联调验收

### 7.1 联调前置条件

| # | 条件 | 状态 |
|---|---|---|
| 1 | 三块圆盘模块已通过 §三 全部检查 | ☐ |
| 2 | 驱动板已通过 §四 全部检查 | ☐ |
| 3 | 映射表已实测填好（§五） | ☐ |
| 4 | 射频基线已测好（§六） | ☐ |
| 5 | 接收机串口已连通（`btnMatrixConnect` 之外的接收机连接） | ☐ |

### 7.2 验收用例

| # | 用例 | 步骤 | 期望 |
|---|---|---|---|
| V1 | 矩阵连接 | UI 点 `btnMatrixConnect` | 日志显示连接成功（版本号已回读） |
| V2 | A 组通道切换 | UI 选通道 1~8 | 日志出现 `>> AA 55 01 01 xx CS` + `<< ... 00 ...` |
| V3 | **B 组独立切换** | 发 `CMD 0x06` 切输出路 | A 组状态不变（用 CMD 0x03 查询确认） |
| V4 | **双组同时设置** | 发 `CMD 0x09 (chA=1, chB=2)` | 两组各自切到指定通道 |
| V5 | 通道切换与接收机一致 | 选 CH3 → UI 发模式设置 | 频谱仪读到有效中频 |
| V6 | 错通道检测 | 矩阵 CH3，接收机发 CH5 | 读数 −∞ 或极低 |
| V7 | 全通道扫测 | 依次选 1~8，每通道测同一频点 | 8 个通道读数量级一致 |
| V8 | 增益报表合理性 | 对比接入矩阵前后的增益值 | 差值应等于 RF 路 + 输出路插损之和 |
| V9 | 断开安全 | 点 `btnMatrixDisconnect` | 双组进入隔离态（CMD 0x05），接收机侧无信号泄漏 |
| V10 | 异常恢复 | 测试中途拔 USB | 上位机报连接断开，不崩溃；重新插入可重连 |

### 7.3 V8 的判读（重要）

**期望**：

```
gain_接入矩阵 − gain_未接矩阵 ≈ (RF路插损) + (输出路插损)
```

**若差值远大于此**，说明存在额外损耗（如接线、SMA 接头不良、模块本身问题），需排查。

**若差值远小于此**，说明可能存在**通道错配** —— 矩阵实际导通的通道与预期不符。回到 §五 复核映射表。

## 八、常见问题排查

| 现象 | 可能原因 | 排查方向 |
|---|---|---|
| 频谱仪读数 −∞（无信号） | 公共端/分路接反；SMA 接头松动；模块未供电 | 先量 CON9→CON1 直通，确认方向；查 VDD |
| 读数正常但切换无效 | 映射表错误；LS 接法反了 | 重做 §五 实测 |
| 读数跳变、随通道乱跳 | 控制线虚接；控制线过长受干扰 | 检查 J4 压接；缩短连线；必要时加 74LVC125 缓冲 |
| 切换瞬间有毛刺 | V4 中间态未生效；控制线无缓冲 | 确认固件执行了 V4 隔离步骤 |
| 8 路读数差异大 | 模块通道间一致性差；或连接器问题 | 逐个复测，排除接触不良 |
| 插损明显超标 | 线缆损耗、接头多次插拔磨损、模块本身老化 | 用直连基准对比；换线缆/接头复测 |
| 上位机连不上 | 驱动为 CH340，设备管理器应见 COMx；波特率不匹配 | 检查设备管理器；确认 115200 |
| ACK 返回 CRC 错误 | 波特率错或干扰 | 确认 115200；缩短串口线；检查接地 |
