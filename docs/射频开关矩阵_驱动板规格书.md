### 1.2 关键设计决策：RF/LO 共用控制线，输出路独立控制

#### 1.2.1 RF 路与 LO 路共用（4 根 GPIO）

**理由**：RF 与 LO 始终成对作用于同一个接收通道。

| 设备 | 通道选择命令 | 含义 |
|---|---|---|
| 接收机 | `0D 11 CH P 00 00 0A` | 接收机内部选通 CH 通道 |
| 矩阵 RF 路 | V1/V2/V3 编码 | 把 RF 信号送到 CH 通道 |
| 矩阵 LO 路 | V1/V2/V3 编码 | 把 LO 信号送到 CH 通道 |

RF 与 LO 送错通道的后果相同（信号进错通道），且两者**永远需要指向同一个通道**，没有需要错开的场景。因此共用同一组控制线，天然同步。

#### 1.2.2 输出路必须独立控制（另 4 根 GPIO）

**理由**：「通道间隔离度」测试需要 RF 输入通道与输出读数通道**故意不同**。

典型测量场景：

```
RF 信号源 → 矩阵 RF 路 → 接收机 CH1 的 RF 口   （注入强信号）
                                        ↓
                              接收机内部串扰
                                        ↓
接收机 CH2 的 IF 输出口 → 矩阵输出路 → 频谱仪   （读漏过来的信号）
```

此时必须满足：
- RF 路切到 **CH1**
- 输出路切到 **CH2**
- 接收机本身工作在 CH2（或按测试项定义处理）

**若三块模块共用控制线，此场景根本无法构造** —— 隔离度测试只能得到恒定无效的结果。

> 项目规划书 §4.3.5 第 16 项「通道间隔离度」当前状态为 **⬜ Stub 占位**，
> 正是等待该能力落地后才实现。

#### 1.2.3 GPIO 总数

| 组 | 信号 | 数量 | 驱动对象 |
|---|---|---|---|
| A 组 | V1 / V2 / V3 / V4 | 4 | 圆盘 #1（RF 路）+ 圆盘 #2（LO 路） |
| B 组 | V1' / V2' / V3' / V4' | 4 | 圆盘 #3（输出路） |

**合计 8 根 GPIO**（STM32F0/G0 资源充裕）。

> **修正记录**：早期方案曾设计为「三块模块全部共用 4 根控制线」，理由是"测试中永远同时切到同一通道"。
> 该假设**不成立** —— 通道间隔离度测试要求 RF 输入通道与输出读数通道不同。
> 方案已修正为 RF/LO 共用 + 输出路独立。

### 1.3 LS 引脚处理

LS（Logic Select）在驱动板上直接短接到 GND，**不引出到圆盘模块**。

- PE42482 的 LS 内部有 1 MΩ 上拉电阻
- LS 接地 → 逻辑 0 → 正码控制
- 三块模块统一正码，固件编码唯一，消除正/反码歧义

**代价**：圆盘模块的 LS 引脚必须在装配时与 GND 短接。圆盘模块上已有 0402 电阻位（丝印 R1~R37），可用其中一脚做 0Ω 短接，或直接在驱动板上把该模块的 LS 排针脚与 GND 线并接。

## 二、PE42482 芯片约束（设计红线）

### 2.1 射频拓扑

| 参数 | 规格 |
|---|---|
| 类型 | SP8T（Single Pole 8 Throw），吸收式（Absorptive） |
| 射频引脚 | **9 个 = 1 公共端 RFC + 8 分路 RF1~RF8** |
| 功能 | **1 路输入 → 8 路输出**，任一时刻仅一路导通 |
| 频率范围 | 10 MHz ~ 8 GHz |
| 插入损耗 | 6–8 GHz 档：typ 1.1 dB / max 1.6 dB |
| 隔离度 | 6–8 GHz 档：30 ~ 34 dB |
| 驻波 | RFC 端口 6–8 GHz 档回波损耗 typ 12 dB |
| 开关时间 | 227 ns（50% 控制 → 90%/10% RF） |
| 功率容量 | 33 dBm CW |
| 线性度 | IIP3 60 dBm，IP2 105 dBm |
| 工作温度 | −40 °C ~ +105 °C |
| 封装 | 24-lead QFN，4 × 4 × 0.85 mm |

### 2.2 ⚠️ 电气红线（违反会损坏芯片）

| 项目 | 限制 | 说明 |
|---|---|---|
| **控制脚绝对最大额定** | **−0.3 V ~ 3.6 V** | V1 / V2 / V3 / V4 / LS **严禁 5 V 驱动** |
| VDD 推荐值 | 2.3 ~ 5.5 V（typ 3.3 V） | 本设计取 **3.3 V** |
| 数字输入高 | ≥ 1.17 V | 3.3 V 满足 |
| 数字输入低 | ≤ 0.6 V | 3.3 V CMOS 满足 |
| 供电电流 | 120 ~ 200 µA | 极小，LDO 余量充足 |

**设计结论**：

1. MCU 必须是 **3.3 V IO** 器件（如 STM32F0/G0、GD32、ESP32-C3），**不得**用 5 V 输出的 MCU 直接驱动
2. 若必须用 5 V IO MCU，必须加电平转换（如 74LVC2T45 / TXS0102）
3. 3.3 V LDO 建议留 100 mA 余量（3 块模块 × 200 µA 实际仅 0.6 mA，LDO 主要为 MCU 与 USB 芯片供电）

### 2.3 去耦与偏置（照搬 pSemi 官方 EVK）

官方评估板 BOM（DOC-75764）元件配置：

| 位号 | 值 | 封装 | 用途 |
|---|---|---|---|
| C1 | 0.1 µF / 50 V / X7R | 0402 | VDD 去耦，**必装**（紧邻芯片 VDD/GND） |
| C2 | 0.1 µF | 0402 | DNI（不装） |
| C3 | 100 pF / 50 V / NP0 | 0402 | VDD 高频去耦，**必装** |
| C4 | 100 pF | 0402 | DNI（不装） |
| R1 | 0 Ω | 0402 | 跳线，**必装**（LS 接地） |
| R2~R8 | 0 Ω | 0402 | DNI（不装） |

**LS 接地通过 R1（0 Ω 0402）实现**，这是官方推荐做法，圆盘模块上已有对应电阻位。

### 2.4 控制逻辑真值表（数据手册 DOC-75785-3 Table 5）

**已确认部分**（数据手册注释 2，原文）：

> LS = don't care, **V4 = 1, V3 = V2 = V1 = 0**, all ports are terminated to provide an all isolated state.

即：**V4 是独立的全隔离位**。置 V4=1 且 V3=V2=V1=0 → 8 个端口全部 50 Ω 终端吸收（安全态）。

**通道编码映射必须实测确认** —— 真值表 PDF 文本化后列对齐存在歧义，且不同批次/版本可能存在差异。

**因此固件必须采用查表映射而非公式推导**，并在首次上电时用实测确定。映射表定义在固件的 `channel_table[8]` 常量数组中，与硬件解耦。

## 三、驱动板硬件设计

### 3.1 器件选型

| 功能 | 推荐型号 | 备选 | 说明 |
|---|---|---|---|
| MCU | **STM32G030F6P6**（Cortex-M0+，LQFP-32，3.3 V IO） | GD32F303 / ESP32-C3 | 3.3 V IO，资源足够，无需外部晶振 |
| USB 转串口 | **CH340C**（内置晶振） | CP2102N | CH340C 省一颗晶振；CP2102 驱动兼容性更稳 |
| LDO | **AMS1117-3.3** 或 ME6211C33M2 | TPS7A2033 | 3.3 V / ≥300 mA |
| 5 V 输入 | USB 5 V 或外部 5 V 端子 | — | 建议同时保留外部 5 V 输入口 |
| 去耦 | 100 nF ×N + 10 µF + 1 µF | — | 每个电源脚就近放置 |
| 连接器（模块侧） | **2.54 mm 排针 / 螺钉端子**（6 位） | — | 见 §3.4 |
| 连接器（串口） | USB Type-C（供电 + 通信） | — | 见 §3.5 |
| 状态指示 | LED ×2（电源 / 通道） | — | 见 §3.6 |

### 3.2 MCU 引脚分配

| MCU 引脚 | 功能 | 方向 | 说明 |
|---|---|---|---|
| PA0 | V1 | 输出 | A 组控制位 1（RF 路 + LO 路） |
| PA1 | V2 | 输出 | A 组控制位 2 |
| PA2 | V3 | 输出 | A 组控制位 3 |
| PA3 | V4 | 输出 | A 组隔离位（1 = 全隔离） |
| PB0 | V1' | 输出 | B 组控制位 1（输出路） |
| PB1 | V2' | 输出 | B 组控制位 2 |
| PB2 | V3' | 输出 | B 组控制位 3 |
| PB3 | V4' | 输出 | B 组隔离位 |
| PA4 | TX | 输出 | → CH340C RXD |
| PA5 | RX | 输入 | ← CH340C TXD |
| PA6 | LED_STATUS | 输出 | 通道指示 |
| PA7 | LED_PWR | 输出 | 电源指示 |
| PA9 / PA10 | USB DM / DP | — | 直连 USB Type-C |
| — | VDD / VSS | — | 3.3 V，旁路 100 nF + 10 µF |
| — | BOOT0 | 下拉 | 10 kΩ → GND |
| — | NRST | 上拉 | 10 kΩ → 3.3 V |

> GPIO 上电默认状态为高阻输入。**固件必须在第一时间把 V4 与 V4' 都置 1（双路隔离）**，再配置 V1~V3 与 V1'~V3'，避免上电瞬间误接通某一路。

### 3.3 控制输出电路

V1~V4 / V1'~V4' 共 8 根线直接由 MCU GPIO 驱动，**不加上下拉电阻、不加驱动芯片**。

理由：
- PE42482 控制脚输入阻抗极高（数据手册：V1~V4 数字输入电流仅 5 µA）
- MCU GPIO 驱动能力（±8 mA @ 3.3 V）远超需求
- 走线长度 < 30 cm，无需缓冲

**唯一要求**：驱动板到圆盘模块的连线采用**双绞或排线**，单根长走线在 227 ns 开关瞬间会有反射，实测中若出现误码再考虑加 74LVC125 缓冲（预留焊盘）。

### 3.4 模块侧接口定义

驱动板提供 **3 组 6 位排针**，每组对应一块圆盘模块：

| 位序 | 信号 | 说明 |
|---|---|---|
| 1 | **VDD_3V3** | 3.3 V 电源（源自驱动板 LDO） |
| 2 | **GND** | 地 |
| 3 | **V1** | 控制位 1（**圆盘 #1/#2 用 A 组；圆盘 #3 用 B 组 V1'**） |
| 4 | **V2** | 控制位 2（同上） |
| 5 | **V3** | 控制位 3（同上） |
| 6 | **V4** | 隔离位（同上） |

**LS 不引出** —— 在驱动板上把该组的 LS 脚与 GND 并接短接。

**A 组 / B 组的分配**：

| 圆盘模块 | 用途 | 控制组 | 端子丝印建议 |
|---|---|---|---|
| #1 | RF 路 | **A 组** | `J_RF: V1 V2 V3 V4` |
| #2 | LO 路 | **A 组** | `J_LO: V1 V2 V3 V4` |
| #3 | 输出路 | **B 组** | `J_IF: V1' V2' V3' V4'` |

> ⚠️ 待确认：圆盘模块 J4（2×4 排针）上 VDD/GND/LS/V1~V4 的**具体脚位**。
> 驱动板排针的位序应按实测的 J4 脚位定义，避免接线错位。
> 若 J4 上 VDD 是 5 V 供电回路，则**不能直接用驱动板 3.3 V 供电**，需改为独立供电并加电平转换 —— 此项须在投板前确认。

### 3.5 上位机通信接口

```
USB Type-C ──► CH340C ──► MCU UART (115200 8N1)
```

- MCU 枚举为 CH340 的虚拟串口，Windows 设备管理器显示为 `COMx`
- 上位机沿用现有 `cmbMatrixPort` / `cmbMatrixBaud`（默认已含 115200）
- **上位机 UI 与 `IChannelSwitcher` 接口无需任何改动**

可选：驱动板额外引出 UART TTL 端子（3.3 V），便于无 PC 场景下用外部工具调试。

### 3.6 状态指示

| LED | 含义 |
|---|---|
| PWR（常亮） | 3.3 V 正常 |
| STATUS | 收到并成功执行一条有效命令时闪 100 ms；通信异常时按错误码规律闪烁 |

STATUS 的闪烁编码建议：

| 模式 | 含义 |
|---|---|
| 单闪 | 命令 CRC 错误 |
| 双闪 | 命令码未知 |
| 三闪 | 通道号越界（不在 1~8） |
| 常亮 | 固件处于错误态（看门狗复位后未通过自检） |

### 3.7 PCB 要求

| 项目 | 要求 | 理由 |
|---|---|---|
| 层数 | **2 层**（有充足铜箔时优先 4 层） | 圆盘模块已用 2 层 FR4 在 8 GHz 验证可行 |

## 四、圆盘模块适配（现成件）

### 4.1 已确认的实物特征（照片实证）

| 特征 | 观察结果 |
|---|---|
| 形状 | 圆形 PCB |
| 射频连接器 | 9 个 SMA（丝印 CON1~CON9），边缘安装式 |
| 公共端标识 | CON9 的走线丝印为 `RFC` |
| 中心器件 | QFN 24 封装，丝印 `BD31 JSJ87T SP8T V1-202504` |
| 控制接口 | J4，2×4 排针 |
| 背面 | 无任何元件 → 底层为完整地平面 |
| 走线风格 | 星型放射状，从芯片扇出到各 SMA |
| 板厚 | 目测约 1.6 mm |

### 4.2 装配前必做检查

| # | 检查项 | 方法 | 判定 |
|---|---|---|---|
| 1 | J4 脚位定义 | 万用表逐脚量对 GND 电阻 | 确认 VDD / GND / LS / V1~V4 |
| 2 | 模块供电电压 | 万用表量 J4 上的 VDD | 若为 5 V → 需独立供电 + 电平转换 |
| 3 | LS 当前接法 | 量 LS 脚对 GND 电阻 | ≈0 Ω（正码）or ≈1 MΩ（反码） |
| 4 | SMA 型号 | 目视 / 卡尺 | 边缘安装 / 螺纹；需配对应线缆 |
| 5 | 插损实测 | 见 §6 | 建立损耗补偿基准 |

**第 3 项若为反码（1 MΩ）**，需在驱动板上把 LS 改接为 VDD（3.3 V）而非 GND；此时三块模块仍需保持一致的 LS 接法。**建议通过更换 R1（0 Ω）位置统一为正码**，避免固件处理两种码制。

### 4.3 三块模块的分配

| 模块 | 用途 | 公共端 RFC 接 | 分路 RF1~RF8 接 |
|---|---|---|---|
| 圆盘 #1 | RF 路 | RF 信号源输出 | 接收机 CH1~CH8 的 RF 输入口 |
| 圆盘 #2 | LO 路 | LO 信号源输出 | 接收机 CH1~CH8 的 LO 输入口 |
| 圆盘 #3 | 输出路 | 接收机 CH1~CH8 的 IF 输出口 | 频谱仪输入 |

> ⚠️ 圆盘模块的公共端是 **RFC**，分路是 **RF1~RF8**。三块模块型号相同，**方向不可接反**。接反后信号会从 8 个分路同时散出，等效于没有切换功能。

### 4.4 输出路的替代方案（待决策）

输出路只有 70 / 750 MHz，用 PE42482 会引入 **0.7 ~ 0.8 dB** 额外插损。

由于增益报表的计算式为 `等效增益 = peak − RF功率`，中频路径的插损会**直接体现在报表数值上**，使增益普遍偏低 0.7 ~ 0.8 dB。

| 方案 | 输出路插损 | 成本 | 说明 |
|---|---|---|---|
| **A. PE42482**（与另两块统一） | 0.7 ~ 0.8 dB | 3 芯片方案下无额外成本 | 插损需在软件中补偿 |
| **B. 50 Ω 继电器** | < 0.1 dB | 4 组双刀继电器 ≈ ¥40 | 需另做一块小驱动板 |

**建议**：若输出精度要求高（Mode3 增益本已存在约 11 dB 偏差待排查），选方案 B；否则先上方案 A，把插损作为标定值写进软件。

## 五、固件需求

### 5.1 上电自检流程

```
1. 立即配置 V4 = 1 且 V4' = 1（双路隔离）、V1~V3 = 0、V1'~V3' = 0
2. 初始化 UART（115200 8N1）
3. 上报版本帧（FW_VER）
4. 进入主循环，等待命令
```

**关键**：V4 与 V4' 置 1 必须**先于** V1~V3 / V1'~V3' 的任何配置，防止上电瞬间误接通。

### 5.2 主循环要求

- 串口中断接收 → 字节缓冲 → 帧解析（定长帧，见协议规范）
- 收到完整且校验通过的帧 → 执行 → 回 ACK
- 命令执行必须**幂等**：重复发送同一条切通道命令不产生异常
- 收到非法帧 → 回错误 ACK，**保持当前通道不变**（不得切到未知状态）
- 看门狗（IWDG）超时周期 ≥ 1 s；喂狗点在主循环

### 5.3 通道切换时序

**A 组（RF 路 + LO 路）**：

| 步骤 | 动作 | 时间 |
|---|---|---|
| 1 | 置 V4 = 1（A 组全隔离） | — |
| 2 | 置 V1~V3 = 新通道编码 | — |
| 3 | 置 V4 = 0（解除隔离） | — |
| 4 | 回 ACK | — |

**B 组（输出路）**：同上，用 V1'~V3' / V4'。

> 步骤 1~3 实际耗时 < 1 µs（PE42482 开关时间 227 ns），但**保留隔离中间态可消除切换瞬间的通道串扰**。
> 代价是切换瞬间有约 1 µs 的全隔离窗口 —— 相对测试节拍（数十 ms）可忽略。

**A 组与 B 组相互独立**：切换 B 组不影响 A 组，反之亦然。这是通道间隔离度测试的基础。

### 5.4 异常与安全

| 异常 | 处理 |
|---|---|
| 串口超时无命令 | 保持当前通道；**不自动回隔离**（避免上位机短时静默导致链路中断） |
| 上位机断开 | 同上。矩阵不应因上位机异常而改变通路状态 |
| 收到越界通道号（<1 或 >8） | 回错误 ACK，状态不变 |
| 收到未知命令码 | 回错误 ACK，状态不变 |
| 校验和不匹配 | 回错误 ACK，状态不变 |
| 看门狗复位 | 复位后进入隔离态并上报复位事件 |

### 5.5 通道编码映射（待实测确认）

 * ⚠️ 映射必须以实测确认为准，不得凭公式推导。
 *    首次上电时逐个驱动 8 组编码并测量哪一路导通，填入本表。 */

### 6.1 数字侧（无需射频仪器）

| # | 测试项 | 方法 | 通过标准 |

### 6.2 射频侧（需信号源 + 频谱仪）

| # | 测试项 | 方法 | 通过标准 |
|---|---|---|---|

## 八、风险登记

| # | 风险 | 等级 | 缓解 |
|---|---|---|---|
| 1 | 7850 MHz 超出芯片 8 GHz 上限仅 150 MHz，实测插损可能超手册 max 值 | **高** | R4 实测；若超标考虑升频方案或改用上限更高的开关芯片 |
| 2 | 通道编码映射填错，信号进入错误通道且不易察觉 | **高** | R1 必做实测；固件用查表；S2 反向验证 |
| 3 | 圆盘模块 J4 脚位不明，接线错位导致芯片损坏（控制脚超 3.6 V） | **高** | 上电前逐脚实测；驱动板加串联 1 kΩ 限流电阻于控制线（可选但推荐） |
| 4 | 输出路 0.8 dB 插损叠加进增益报表 | 中 | 软件标定补偿；或改用继电器 |
| 5 | 3 块模块间插损不一致 | 中 | R6 实测；软件按模块分别补偿 |
| 6 | Mode3 增益原有约 11 dB 偏差未定位，矩阵引入后会掩盖根因 | 中 | 先关闭矩阵复现原始偏差，再引入矩阵 |
