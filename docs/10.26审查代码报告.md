## 2. 🔴 严重级问题

### #1 🆕 增益不一致性判定只看极差，完全忽略规格区间

**位置**：[AutoTest/Shared/GainConsistencyCalculator.cs:99](file:///d:/JProgram/2026/A205自动测试系统/AutoTest/Shared/GainConsistencyCalculator.cs#L99)、[InstrumentControl/TestItems/ChannelGainInconsistencyTest.cs:254](file:///d:/JProgram/2026/A205自动测试系统/InstrumentControl/TestItems/ChannelGainInconsistencyTest.cs#L254)

**问题**：

`GainConsistencyCalculator.Compare` 计算 `Range = gains.Max() - gains.Min()`，判定直接使用 `comparison.RangePass`（即 `Range <= 1.0 dB`）。

而增益规格区间定义在 [InstrumentControl/TestItems/GainTest.cs:58-60](file:///d:/JProgram/2026/A205自动测试系统/InstrumentControl/TestItems/GainTest.cs#L58-L60)：

```csharp
private const double Mode1Center = 20.0, Mode1Tol = 2.0;   // [18.0, 22.0]
private const double Mode2Center = 10.0, Mode2Tol = 1.0;   // [ 9.0, 11.0]
private const double Mode3Center = 20.0, Mode3Tol = 1.5;   // [18.5, 21.5]
```

**失效场景**：三通道增益全部为 30 / 30.5 / 30.9 dB —— 相对 Mode1 规格 \[18,22] 整体超出 8 dB，但极差仅 0.9 ≤ 1 → **判定 Pass**。

`GainConsistencyCalculator.IsInRange`（`:106`）虽然提供了单值区间判定，但**只在 AGC 起控项被逐频点调用**（[ChannelGainInconsistencyAgcOnTest.cs:204](file:///d:/JProgram/2026/A205自动测试系统/InstrumentControl/TestItems/ChannelGainInconsistencyAgcOnTest.cs#L204)），**AGC 不起控项完全没有引用它**。

**影响**：产品增益整体偏离规格但通道间一致时，系统报"通道间一致性好 = Pass"，掩盖了增益本身超差的事实。

**建议**：Pass 判定需同时满足两个条件：

1. 每个频点增益 ∈ 该模式规格区间（`IsInRange`）
2. 极差 ≤ 1 dB（`RangePass`）

建议在 `Comparison` 中新增 `AllInRange` 属性集中承载条件 1，避免在两处调用点重复实现。

### #4 🆕 关窗时不取消运行中的测试 → 信号源退出后仍在发射载波

**位置**：[UI/MainForm.cs:62-73](file:///d:/JProgram/2026/A205自动测试系统/UI/MainForm.cs#L62-L73)、[UI/AutoTestPanel.cs:120-151](file:///d:/JProgram/2026/A205自动测试系统/UI/AutoTestPanel.cs#L120-L151)

**问题**：

`MainForm.OnFormClosing` 只调用了 `receiverControlPanel?.ShutdownInstruments()`，**未先取消** **`AutoTestPanel._runCts`**；`AutoTestPanel.Dispose` 中同样没有 `Cancel`。

**竞态序列**：

1. 一键运行进行中，测试项正在向仪表发送 SCPI
2. 操作员关闭窗体 → `OnFormClosing` → `ShutdownInstruments()` 关闭 RF/LO 输出

**影响**：这正是 `MainForm.cs:53-58` 注释中明确写出的收口目的——"信号源持续发射载波"——所指向的危险状态。另：`_runCts` 泄漏；`InBandSpuriousFreqForm` 的等待方永挂。

**建议**：`MainForm.OnFormClosing` 中先调用 `autoTestPanel.RequestStopAll()`（内部执行 `_runCts?.Cancel()` 并短暂等待收尾），**再**执行仪表收口。当前代码库中 `AutoTestPanel` 没有任何对外的停止入口，需新增。
