### P0-1 工装矩阵为空实现 —— 多通道测试在物理上不可能正确

**状态：已确认，按用户决定暂不修复（协议未到位），仅做风险登记与使用约束。**

**位置**：`MatrixControl/MatrixSerialPort.cs`

```csharp
public bool IsConnected => false;                          // :15  恒为 false

public void Connect(string portName, int baudRate = 9600)  // :24-30
{
    _portName = portName;
    Logger.Log($"[Matrix] protocol not ready, called Connect({portName}, {baudRate})");
    ConnectionChanged?.Invoke(false);                     // 从不真正打开串口
}

public void SwitchChannel(int channel)                     // :41-44
{
    Logger.Log($"[Matrix] protocol not ready, called SwitchChannel({channel})");
}
```

**问题本质**：规划书 §4.1.4 明确"先发送工装矩阵切换命令，待切换完成后再发送接收机通道选择命令"，但当前实现是**接收机单方面切换、射频路径不动**。

| 环节 | 现状 |
|---|---|
| `OnChannelSelected` → `_matrix.SwitchChannel(N)` | 只打日志，射频路径不动 |
| 各测试项 `SendChannelThenModeCommand(_channel, mode)` | **只切接收机，不碰矩阵** |
| `Tests/` 全域 grep `Matrix` | `InstrumentControl/TestItems/` 下**零命中** |

**后果**：批量跑 8 通道时，通道 2~8 实际测量的是通道 1 的通路。报告会正常生成、判定会正常输出 `Pass`，**不产生任何异常或告警**。

**这是本次审查中唯一"不会被任何现有测试拦截"的灾难级风险** —— 因为矩阵本身没有实现，也就没有任何测试会失败。

**用户决定（2026-10-20）**：矩阵协议尚未到位，等协议到位后再接入，**本次不改动这部分代码**。

**协议到位后必须完成的事项**：
1. 实现 `MatrixSerialPort.Connect` / `SwitchChannel` 的真实串口收发
2. `SwitchChannel` 必须等待硬件切换完成（需与硬件确认响应机制或稳定时间）
3. 在 `LoadDefaultTestsToGrid` / 各测试项的通道切换流程中，先切矩阵、再切接收机（规划书要求顺序）
4. **强烈建议**：接入前在 UI 上禁用通道 2~8 并阻断自动测试入口，避免继续产出废数据

### 3.2 带外抑制：单位为 dBm，判定方向可能相反

**位置**：`InstrumentControl/TestItems/OutOfBandRejectionTest.cs`

```csharp
// :390  判据
bool pass = !double.IsNaN(maxSegmentDb) && maxSegmentDb >= limit;   // limit = 25 (Mode1/2) 或 60 (Mode3)

// :14  注释自认
/// 单位 dBm（按用户 Q3-B 决策：先按 dBm 把测试跑通，后续可以切换为 dBc）
```

**问题本质**：抑制比本质是"基波功率 − 带外信号功率"，单位应为 **dBc**，且**数值越大越好**。当前测的是带外信号的**绝对功率（dBm）**：

**反例推演**：
- 带外信号 −90 dBm（抑制 excellent）→ `−90 >= 25` 为 **False** → 判 **Fail**
- 带外信号 −10 dBm（抑制极差）→ `−10 >= 25` 为 **False** → 判 **Fail**

**无论产品质量好坏都会判 Fail**，该测试项当前**不具备有效性**。

**关联疑点**：Mode3 的 SA 扫频段为 `1090~6000 MHz` + `100~410 MHz`（`:88-91`），**完全未覆盖 750 MHz（Mode3 中频）附近的带外区域**，与"测中频滤波器带外抑制"的方法学定义不符 —— 即使修正判据方向，Mode3 的测量对象本身也需要复核。

**待确认**：
1. 带外抑制的业务定义究竟是 dBm 还是 dBc？判定方向是"越大越好"还是"越小越好"？
2. Mode3 的 SA 扫频段是否应覆盖 750 MHz 附近？
